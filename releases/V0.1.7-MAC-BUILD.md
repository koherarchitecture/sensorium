## Prerequisites

- Both Rust targets installed: `aarch64-apple-darwin` (default on Apple Silicon) and `x86_64-apple-darwin`. Confirm with `rustup target list --installed`. If `x86_64-apple-darwin` is missing: `rustup target add x86_64-apple-darwin`.
- Tauri CLI darwin binding present at `node_modules/@tauri-apps/cli-darwin-arm64/`. If `npm install` ever produced a Linux binding (Dropbox-synced `node_modules` from a prior Linux build can cause this), nuke and reinstall: `rm -rf node_modules package-lock.json && npm install`.
- `~/.local/bin/cc` shadow workaround: builds may need `PATH="/usr/bin:$PATH"` prefix to avoid a `cc` from `~/.local/bin/` interfering with Apple's clang.
- GitHub auth status irrelevant — this brief does not push regardless. See the **Release Artefact Push Discipline** rule in `tools-scratch/CLAUDE.md`.

## Steps

```bash
# 1. Confirm host.
uname -s -m
# expect: Darwin arm64

# 2. Move to the repo and align with the v0.1.7 source state.
cd ~/Dropbox/personal_projects/koher/tools-release/sensorium
pkill -f tauri 2>/dev/null
rm -rf src-tauri/target/aarch64-apple-darwin/release src-tauri/target/x86_64-apple-darwin/release dist
git fetch origin --force --prune
# If a v0.1.7 branch has been cut, check it out:
#   git checkout v0.1.7 && git reset --hard origin/v0.1.7
# Otherwise build off the working tree (the source-complete state is on disk).
git config user.name "Koher Architecture"
git config user.email "hello@koher.app"

# Confirm the version bump landed.
grep '"version"' package.json src-tauri/tauri.conf.json
grep '^version' src-tauri/Cargo.toml
# expect: all three say 0.1.7

# 3. Restore the darwin Tauri CLI native binding.
rm -rf node_modules package-lock.json
npm install
ls node_modules/@tauri-apps/cli-darwin-arm64 >/dev/null && echo "darwin binding OK"

# 4. Sync the canonical Koher UI CSS into src/assets/.
bash scripts/sync-koher-ui.sh

# 5. Build the aarch64 (Apple Silicon) .dmg.
#    PATH override avoids the ~/.local/bin/cc shadow that can interfere
#    with Apple clang. Build time ~2 min from a warm cache.
PATH="/usr/bin:$PATH" ./node_modules/.bin/tauri build --target aarch64-apple-darwin

# 6. Build the x86_64 (Intel) .dmg.
#    Cross-compile target. Build time ~1 min 40 s from a warm cache.
PATH="/usr/bin:$PATH" ./node_modules/.bin/tauri build --target x86_64-apple-darwin

# 7. Stage both artefacts.
cp src-tauri/target/aarch64-apple-darwin/release/bundle/dmg/sensorium_0.1.7_aarch64.dmg releases/macos-aarch64/
cp src-tauri/target/x86_64-apple-darwin/release/bundle/dmg/sensorium_0.1.7_x64.dmg releases/macos-x64/

# 8. Compute SHA-256 for BUILD-STATUS table.
shasum -a 256 \
  releases/macos-aarch64/sensorium_0.1.7_aarch64.dmg \
  releases/macos-x64/sensorium_0.1.7_x64.dmg

# 9. Commit only. Do NOT push.
#    Per the Release Artefact Push Discipline rule in tools-scratch/CLAUDE.md
#    (binding 9 May 2026): commits adding .dmg/.deb/.flatpak under releases/
#    must NOT be pushed without explicit user "release"/"ship" instruction.
git add releases/macos-aarch64/sensorium_0.1.7_aarch64.dmg releases/macos-x64/sensorium_0.1.7_x64.dmg
git commit -m "release(macos): sensorium 0.1.7 aarch64 .dmg + x64 .dmg (build-only, local-only, not released)"
# Skip git push entirely.
```
