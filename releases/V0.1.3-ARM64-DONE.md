- **Re-install `node_modules` before any Mac build.** Section "`node_modules/` is now Linux-flavoured" above. Cross-platform binding trap. Not urgent for the release cut itself.
- **Build-machine masking is still a thing on the Mac.** Same caveat from AMD64-DONE — any smoke test of the Mac DMG on the Mac that produced it tells you nothing about whether the v0.1.3 calibration fixes work on a user machine, because the compile-time-manifest fallback in `flavour::load_flavour` will silently succeed via the source-tree path on disk. The amd64 flatpak sandbox smoke test (Linux box) and the arm64 flatpak sandbox smoke test (this session) are the two sandboxed verifications we have. Both passed. Mac DMG is trusted by code-path transitivity.
- **`[ahead 5]` is expected, not a bug.** The five local-only commits are the four artefact commits + the two ARM64-BUILD docs commits. They stay local; the release tag points at `d835413` (source). Do not push the branch.
- **Do not `git reset --hard origin/v0.1.3`.** Would erase all five local-only commits and the six artefacts from the working tree (well — the four artefact commits' files; the docs commits don't carry artefacts). Same prohibition as in the runbook.
- **Suggested-tone cues are non-interactive.** Carried over from AMD64-DONE. If anyone looks at the cue pills and tries to click them, the original click-to-insert design was reverted per Prayas's 21 May direction. Final behaviour: display-only, system-selected.
